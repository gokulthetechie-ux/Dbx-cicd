# Dbx-cicd

Databricks pipelines, warehouse, jobs and cicd workflows

## Repository Structure

- `.github/` - GitHub workflows and CI/CD configuration
- `config/` - Configuration files for Databricks deployments
- `jobs/` - Databricks job definitions and schedules
- `notebook/` - Databricks notebooks
- `scripts/` - Deployment and utility scripts
- `sql/` - SQL scripts for warehouse and table management
- `tests/` - Unit and integration tests
